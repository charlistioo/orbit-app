# ORBIT
## Spend freely, stay aware.

Saya ingin membuat sebuah aplikasi mobile bernama ORBIT.

Tagline:

"Spend freely, stay aware."

Sebelum membuat kode, pahami terlebih dahulu konsep produk, masalah yang ingin diselesaikan, perilaku user, fitur utama, dan filosofi aplikasi ini.

Jangan menganggap ORBIT sebagai aplikasi pencatatan keuangan biasa.

ORBIT lebih berfokus pada perilaku konsumtif seseorang.

==================================================
1. APA ITU ORBIT?
==================================================

ORBIT adalah aplikasi mobile yang membantu seseorang memahami pola konsumsi dan perilaku pengeluarannya sehari-hari.

Target utama:

- mahasiswa
- pelajar
- pekerja muda
- orang yang memiliki uang atau penghasilan tetapi kurang sadar terhadap pola konsumsi mereka
- orang yang sering membeli makanan, kopi, minuman, camilan, self-reward, atau konsumsi lainnya
- orang yang pengeluarannya dapat berubah berdasarkan keinginan, kondisi, dan mood

ORBIT bukan aplikasi accounting.

ORBIT bukan aplikasi budgeting yang ketat.

ORBIT bukan aplikasi yang mengunci pengeluaran.

ORBIT bukan aplikasi yang memaksa user mencatat semua transaksi.

Fokus ORBIT adalah:

MEMBANTU USER MENYADARI POLA KONSUMSINYA.

==================================================
2. MASALAH YANG INGIN DISELESAIKAN
==================================================

Banyak orang sebenarnya memiliki kemampuan finansial tertentu untuk konsumsi sehari-hari.

Namun mereka tidak selalu mengetahui:

- berapa banyak uang yang mereka keluarkan untuk konsumsi
- konsumsi apa yang paling sering mereka lakukan
- kapan pengeluaran mereka meningkat
- kapan mereka mengubah rencana konsumsi
- seberapa sering mereka melakukan self-reward
- bagaimana perubahan mood berkaitan dengan perubahan pola pengeluaran
- apakah pengeluaran mereka masih sesuai dengan kemampuan yang mereka tentukan sendiri

Contoh:

Hari ini seseorang merasa senang.

Dia membeli kopi.

Kemudian membeli makanan yang lebih mahal.

Kemudian membeli dessert.

Kemudian melakukan self-reward.

Secara individual, transaksi tersebut terlihat kecil.

Namun jika terus dilakukan, pengeluaran konsumtif dapat menjadi kebocoran finansial.

Masalah yang ingin diselesaikan ORBIT bukan:

"Bagaimana membuat user tidak boleh membeli sesuatu?"

Tetapi:

"Bagaimana membuat user sadar terhadap pola konsumsi mereka?"

==================================================
3. FILOSOFI UTAMA
==================================================

ORBIT memiliki prinsip:

"Spend freely, stay aware."

User tetap bebas menggunakan uangnya.

User bebas membeli sesuatu.

User bebas mengubah rencana.

User bebas mengubah budget.

User bebas mengubah mood.

User bebas tidak mengikuti rekomendasi aplikasi.

ORBIT tidak mengunci user.

ORBIT tidak mempermalukan user.

ORBIT tidak mengatakan:

"Kamu boros."

"Kamu tidak disiplin."

"Kamu tidak boleh membeli ini."

Sebaliknya, ORBIT memberikan informasi dan insight.

Contoh:

atau:

"Beberapa hari terakhir pengeluaran kopi kamu meningkat."

Tujuan akhirnya adalah:

USER TETAP BEBAS,
TETAPI LEBIH SADAR.

Jenis konsumsi harus mengikuti kebutuhan dan kebiasaan masing-masing user.

Contoh user A:

- makanan
- kopi
- camilan
- self reward

User B:

- makan
- transportasi online
- gaming
- kopi
- entertainment

User C:

- makanan
- rokok
- kopi
- skincare
- shopping

ORBIT tidak boleh mengasumsikan semua orang memiliki kategori konsumsi yang sama.

Contoh:

User membuat:

"Kopi"

Kemudian:

"Self Reward"

Kemudian:

"Jajan"

Kemudian:

"Gaming"

==================================================
5. KATEGORI KONSUMSI DIBENTUK OLEH USER
==================================================

Saat membuat rencana, user dapat memilih kategori yang sudah pernah digunakan.

Jika belum ada:

user dapat membuat kategori baru.

Contoh:

User mengetik:

"Kopi"

Maka kategori:

Kopi

disimpan.

Di kemudian hari ketika user ingin membuat rencana baru:

Kopi

akan muncul sebagai pilihan.

Tujuannya adalah:

USER TIDAK PERLU MENULIS ULANG KATEGORI YANG SAMA.

Tidak perlu menggunakan:

- fuzzy matching
- similarity
- AI classification
- semantic matching
- text normalization

ORBIT cukup berpedoman pada input user.

Apa yang user buat dan simpan akan menjadi history untuk digunakan kembali.

==================================================
6. TIDAK ADA KEWAJIBAN MENCATAT
==================================================

Ini merupakan prinsip penting.

ORBIT TIDAK BOLEH membuat user merasa:

"Saya harus membuka aplikasi setiap kali membeli sesuatu."

Tidak semua transaksi harus dicatat.

Tidak ada sistem penalti jika user tidak mencatat.

Tidak ada streak wajib.

Tidak ada hukuman.

Tidak ada lock.

Tidak ada requirement bahwa user harus mengisi aplikasi setiap hari.

ORBIT hanya memberikan fasilitas agar pencatatan menjadi mudah bagi user yang memang ingin menggunakannya.

Prinsip:

"Kalau user memang ingin sadar dengan konsumsi mereka, mereka akan terus menggunakan aplikasi."

==================================================
7. REMINDER PENCATATAN
==================================================

Walaupun pencatatan tidak wajib, ORBIT boleh memberikan reminder yang ringan.

Reminder tidak boleh terasa memaksa.

Contoh:

Makanan:
Rp30.000

Kopi:
Rp16.000

Self Reward:
Rp15.000

Saat user membuka ORBIT kembali, aplikasi dapat menunjukkan:

"Untuk kategori Kopi yang kamu rencanakan hari ini, sudah ada pengeluaran?"

Pilihan:

[ Sudah ]

[ Belum ]

[ Tidak ada pengeluaran ]

Jika user memilih:

"Tidak ada pengeluaran"

maka tidak ada transaksi yang dibuat.

Jika user memilih:

"Sudah"

user dapat langsung memasukkan transaksi.

==================================================

Consumption Bank BUKAN uang sungguhan.

Bukan rekening.

Bukan saldo bank.

Contoh:

Rp16.000

Rp12.000

Selisih:

Rp4.000

Maka:

+Rp4.000

Rp96.000

Rp100.000.

Ini memberikan efek psikologis:

"Karena kemarin saya mengeluarkan lebih sedikit dari rencana, saya punya fleksibilitas."
